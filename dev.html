Выбери новый HTML-файл игры (полный экспорт из TurboWarp). Сайт сам разобьёт его на части, заменит старые и опубликует обновление для всех посетителей. Мелкие правки главной страницы через эту кнопку не отправляются — только игра.

🔑 GitHub-токен (нужен один раз)

Токен даёт этой странице право публиковать обновления в твой репозиторий:

  1. Открой страницу создания токена (ты уже залогинен в GitHub)
  2. Нажми внизу Generate token
  3. Скопируй его (ghp_…) и вставь ниже
