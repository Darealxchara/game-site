# Сайт игры (готов к публикации)

Бесплатный одностраничный сайт под браузерную игру: описание, скриншоты,
кнопка **«Играть в браузере»** (игра открывается прямо на странице) и
кнопка **«Скачать»**. Чистый HTML/CSS/JS, без сборщиков и зависимостей.

## Структура

```
game-site/                (всё в одной папке — так удобно заливать на GitHub)
├── index.html          ← описание игры, ссылки (тут всё правится)
├── style.css           ← внешний вид
├── app.js              ← поведение: окно игры, проверка файлов
├── favicon.svg
├── project.html        ← игра из TurboWarp (52 МБ)
├── game.zip            ← архив для скачивания
└── 1.png, 2.png, 3.png ← скриншоты
```

## Что отредактировать

Откройте `index.html`, блок `GAME` в самом начале:

```js
title:   "Название игры",     // название
tagline: "Короткий слоган",   // подзаголовок под названием
version: "1.0",
build:   "project.html", // путь к игре
zip:     "game.zip",     // путь к архиву
itch:    "",                  // ссылка на itch.io (пусто = не показывать)
github:  "",                  // ссылка на GitHub (пусто = не показывать)
features:[ ... ],             // три карточки «О игре»
shots:   [ ... ]              // скриншоты
```

Всё остальное (заголовок вкладки, og-теги, подвал) подставится само.

## Как бесплатно выложить

### Вариант A — itch.io (самый быстрый, 5 минут)

Свой сайт тогда просто лежит отдельно, а сама игра живёт на itch.io.

1. Зарегистрируйтесь на **itch.io** (бесплатно).
2. `Dashboard` → `Create new project`.
3. Заполните название, описание, жанр.
4. `Upload files` → выберите архив со сборкой.
5. В настройках файла поставьте **This file will be played in the browser**.
6. itch.io сам покажет игру на вашей странице `username.itch.io/game`.

Ограничений по скачиванию нет, платить не нужно.

### Вариант B — свой сайт на GitHub Pages (бесплатно)

1. Создайте аккаунт на **github.com**.
2. `New repository` → имя `game-site` → **Public** → Create.
3. На странице репозитория `Add file` → `Upload files` → перетащите
   **всё содержимое папки `game-site`** (10 файлов, все лежат в корне).
4. `Settings` → `Pages` → `Source: Deploy from a branch` →
   ветка `main` / папка `/ (root)` → **Save**.
5. Через 1–2 минуты сайт появится:
   `https://username.github.io/game-site/`

Обновление: просто перезаливайте изменённые файлы (Replace).

### Вариант C — Cloudflare Pages (бесплатно, свой адрес вида `xxx.pages.dev`)

1. Аккаунт на **dash.cloudflare.com** → `Workers & Pages` → `Create` → вкладка **Pages**.
2. `Upload assets` → назовите проект → перетащите папку целиком.
3. `Deploy site` → через минуту адрес `проект.pages.dev`.
4. Обновление: `Create deployment` → снова перетащите файлы.

Лимит Cloudflare: **25 МБ на один файл**. Экспорт TurboWarp обычно
укладывается; если больше — используйте GitHub Pages (лимит файла ~100 МБ).

## Проверка перед публикацией

Просто откройте `index.html` двойным кликом в браузере. Должно:
- показаться название, карточки, скриншоты-заглушки;
- по клику «Играть» — открыться окно игры (или понятная подсказка,
  что файл ещё не положили);
- не должно быть красных ошибок в консоли (F12).

## Частые вопросы

**Игра не открывается в iframe?**
Некоторые сборки запрещают встраивание заголовком `X-Frame-Options`.
В экспорте TurboWarp такой проблемы нет, но если вдруг — откройте
`project.html` в консоли и уберите строку с `X-Frame-Options`,
либо вынесите игру в отдельную вкладку (замените iframe на ссылку).

**Хочу, чтобы игра открывалась на весь экран сразу**
Кнопка `⛶` в окне игры использует Fullscreen API. Для автополного
экрана добавьте `frame.requestFullscreen()` сразу после `frame.src = ...`
в `app.js`.

**Нужен свой домен (мой-сайт.ru)**
Бесплатно такого нет: домен стоит ~100–300 ₽/год. Можно подключить
купленный домен к GitHub Pages или Cloudflare Pages — настройка бесплатная,
платить нужно только за сам домен.
